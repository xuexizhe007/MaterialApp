# APK 构建说明

## v2.1.3 界面调整

本版本基于 v2.1.2，保留已验证可打包的 Android 构建配置，并完成以下界面优化：

- 去除各底部主页面顶部标题；
- 分页控件改为跟随条目列表显示，不再固定悬浮在页面底部；
- 入库、出库“新增一项”改为新增在已有物资上方；
- 底部 Tab “出入库”改为“查询”；
- 出入库统计时间区域改为紧凑布局：
  - “统计时间”和两个日期框在同一行；
  - 两个日期框中间使用 “-”；
  - 不再显示“开始：”“结束：”；
  - 近 7 天、近 1 个月、近 3 个月、近 1 年四个按钮在同一行并缩小；
  - 删除说明文字；
- 目录页去掉“库存排序”文字和下拉框，改为搜索框右侧箭头按钮，点击切换库存升序/降序。

## 推荐构建步骤

进入项目根目录 `MaterialApp-main` 后执行：

```bash
flutter clean
flutter pub get
flutter build apk
```
